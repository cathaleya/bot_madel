## BUTIR INSTRUMEN

### DIMENSI 1: LITERASI INFORMASI DIGITAL (C1 - LID)

#### Butir 1
**Skenario:** Anda sedang mencari referensi jurnal untuk menyusun tugas makalah akhir semester. Saat mencari di Google dengan kata kunci umum, muncul ratusan ribu hasil yang bercampur antara blog opini dan artikel ilmiah. Bagaimana respons Anda?

**Opsi Jawaban:**
1. [Skor 1] Mengambil kutipan langsung dari artikel blog pertama yang muncul agar cepat selesai.
2. [Skor 2] Membaca judul beberapa artikel dan mengutip tanpa membaca isi utuhnya.
3. [Skor 3] Membaca abstrak dari beberapa PDF teratas dan merangkumnya.
4. [Skor 4] Menggunakan fitur Advanced Search dan memfilter hasil khusus jurnal akademik.
5. [Skor 5] Mengevaluasi metodologi riset dari database akademik resmi sebelum mengutipnya.

#### Butir 2
**Skenario:** Anda menemukan video TikTok viral tentang 'metode kilat mengajar calistung' yang diklaim terbukti ampuh, namun tidak mencantumkan sumber rujukan akademis apa pun. Bagaimana respons Anda?

**Opsi Jawaban:**
1. [Skor 1] Langsung membagikannya ke grup WA kelas mahasiswa karena videonya menarik.
2. [Skor 2] Menonton videonya lalu langsung mempraktikkannya saat simulasi mengajar.
3. [Skor 3] Membaca kolom komentar; jika banyak yang memuji, Anda akan mencoba metode tersebut.
4. [Skor 4] Mencari tahu validitas metode tersebut di jurnal pendidikan atau sumber resmi.
5. [Skor 5] Menganalisis kesesuaian metode video tersebut dengan teori pedagogik secara kritis.

#### Butir 3
**Skenario:** Laptop Anda dipenuhi ratusan file PDF materi kuliah, tugas, dan RPP yang menumpuk di folder Downloads. Apa tindakan Anda?

**Opsi Jawaban:**
1. [Skor 1] Membiarkan file tetap di Downloads dan menggunakan fitur search saat butuh.
2. [Skor 2] Memindahkan semua file ke satu folder baru tanpa pengelompokan lebih lanjut.
3. [Skor 3] Membuat folder terpisah untuk setiap mata kuliah secara berkala.
4. [Skor 4] Membuat hierarki folder dan mengubah nama file menggunakan format standar.
5. [Skor 5] Merancang arsitektur folder hierarkis yang tersinkronisasi otomatis dengan cloud storage.

#### Butir 4
**Skenario:** Anda diminta merancang strategi pembelajaran untuk siswa. Anda memiliki data hasil evaluasi nilai harian siswa dalam bentuk spreadsheet. Apa yang Anda lakukan?

**Opsi Jawaban:**
1. [Skor 1] Mengabaikan data spreadsheet dan mengajar menggunakan gaya ceramah standar.
2. [Skor 2] Melihat sekilas siapa siswa yang nilainya paling rendah dan hanya fokus pada mereka.
3. [Skor 3] Menghitung rata-rata nilai kelas untuk menentukan pengulangan materi umum.
4. [Skor 4] Menggunakan fitur sortir Excel untuk memetakan kelompok siswa yang butuh remidial.
5. [Skor 5] Memvisualisasikan data ke dalam grafik untuk mengidentifikasi topik spesifik yang sulit.

#### Butir 5
**Skenario:** Kelompok Anda sedang menyusun laporan PKL secara kolaboratif, namun salah satu teman mengeluh flashdisknya terkena virus. Bagaimana Anda mengelola data ini?

**Opsi Jawaban:**
1. [Skor 1] Meminta file dari flashdisk teman tersebut disalin langsung ke laptop Anda.
2. [Skor 2] Mengirimkan file bolak-balik melalui WhatsApp Group secara manual.
3. [Skor 3] Mem-backup file ke email pribadi setiap kali selesai mengerjakan bagian Anda.
4. [Skor 4] Memindahkan proyek ke platform cloud agar tidak bergantung pada flashdisk fisik.
5. [Skor 5] Mengelola dokumen di cloud dengan pengaturan hak akses dan fitur Version History.

#### Butir 6
**Skenario:** Dosen memberikan tugas menyusun kerangka latar belakang makalah. Anda kebingungan mencari ide dan teringat aplikasi ChatGPT. Bagaimana cara Anda menggunakannya?

**Opsi Jawaban:**
1. [Skor 1] Menyalin instruksi tugas ke ChatGPT, lalu mengumpulkan hasilnya mentah-mentah.
2. [Skor 2] Menyalin output ChatGPT lalu mengganti beberapa kata agar tidak terdeteksi plagiasi.
3. [Skor 3] Menggunakan ChatGPT untuk draf awal, lalu memperbaikinya sendiri sebelum dikumpulkan.
4. [Skor 4] Menggunakan AI untuk brainstorming ide dan menyusun outline tulisan mandiri.
5. [Skor 5] Menyusun sintesis mandiri dengan mengonfirmasi rujukan asli dari ide pokok AI.

### DIMENSI 2: KOMUNIKASI & KOLABORASI LITERASI (C2 - KKL)

#### Butir 7
**Skenario:** Anda ingin meminta izin kepada dosen karena tidak bisa hadir perkuliahan daring akibat kendala kesehatan darurat. Langkah apa yang Anda ambil?

**Opsi Jawaban:**
1. [Skor 1] Titip absen di grup WA kelas tanpa memberi tahu dosen pengampu.
2. [Skor 2] Mengirim pesan chat pribadi di luar jam kerja dengan bahasa santai.
3. [Skor 3] Mengirim pesan chat ke dosen di jam kerja dengan alasan izin jelas.
4. [Skor 4] Mengirim email resmi dengan format baku disertai lampiran surat keterangan sakit.
5. [Skor 5] Mengirim laporan izin resmi beserta komitmen untuk mengejar ketertinggalan materi.

#### Butir 8
**Skenario:** Anda menyusun ringkasan materi ujian yang sangat lengkap. Rekan beda kelas meminta ringkasan tersebut. Apa yang Anda lakukan?

**Opsi Jawaban:**
1. [Skor 1] Menjual file PDF ringkasan tersebut di grup angkatan demi keuntungan pribadi.
2. [Skor 2] Mengirimkan file langsung ke satu per satu mahasiswa yang meminta via DM.
3. [Skor 3] Membagikan file tersebut secara bebas di satu grup WhatsApp angkatan.
4. [Skor 4] Mengunggah ringkasan ke Google Drive angkatan agar mudah diakses semua orang.
5. [Skor 5] Membagikan file di cloud angkatan dengan mencantumkan rujukan sumber aslinya.

#### Butir 9
**Skenario:** Kelompok Anda mendapat tugas merancang RPP berkelompok, namun anggota terpisah di berbagai kota. Bagaimana Anda mengoordinasi tugas?

**Opsi Jawaban:**
1. [Skor 1] Satu orang mengerjakan seluruhnya lalu semua nama dimasukkan ke laporan.
2. [Skor 2] Membagi tugas di WA dan masing-masing mengirimkan file terpisah nanti digabung.
3. [Skor 3] Mengadakan rapat Zoom untuk membagi tugas, lalu dikerjakan di Word masing-masing.
4. [Skor 4] Membuat Shared Document agar semua orang bisa mengerjakan langsung di satu file.
5. [Skor 5] Menggunakan Shared Document terintegrasi dengan alat manajemen tugas transparan.

#### Butir 10
**Skenario:** Saat PLP, Anda ditugaskan menginformasikan tugas mandiri kepada grup WhatsApp orang tua siswa. Bagaimana Anda menyampaikannya?

**Opsi Jawaban:**
1. [Skor 1] Mengirim foto papan tulis tugas tanpa teks pengantar apa pun di grup.
2. [Skor 2] Mengirim pesan singkat meminta orang tua menyuruh anaknya mengerjakan tugas.
3. [Skor 3] Mengirim pesan dengan sapaan standar beserta detail tugas dan batas waktu.
4. [Skor 4] Menulis pesan terstruktur dengan bahasa Indonesia baku dan sopan kepada wali murid.
5. [Skor 5] Menulis pesan terstruktur disertai media visual ringkas untuk memperjelas instruksi.

#### Butir 11
**Skenario:** Anda menjadi moderator diskusi di Google Meet. Salah satu peserta terus memotong pembicaraan orang lain. Tindakan Anda?

**Opsi Jawaban:**
1. [Skor 1] Membiarkan saja karena merasa bukan kapasitas mahasiswa untuk menegur teman.
2. [Skor 2] Langsung mengeluarkan peserta yang memotong pembicaraan tersebut dari pertemuan.
3. [Skor 3] Mematikan mikrofon peserta yang memotong secara sepihak tanpa penjelasan.
4. [Skor 4] Menegur secara verbal dengan sopan dan mengingatkan aturan diskusi forum.
5. [Skor 5] Melakukan intervensi empatik untuk mengatur alur pembicaraan sesuai antrean.

#### Butir 12
**Skenario:** Anda ingin memperluas wawasan pedagogik dari praktisi di luar kampus. Apa yang Anda lakukan?

**Opsi Jawaban:**
1. [Skor 1] Merasa ilmu dari dosen kampus sendiri sudah cukup dan tidak mencari luar.
2. [Skor 2] Mengikuti akun hiburan di media sosial untuk melepaskan stres kuliah.
3. [Skor 3] Sesekali melihat video tips mengajar di YouTube jika kebetulan muncul di beranda.
4. [Skor 4] Bergabung aktif di komunitas guru digital untuk bertukar RPP dan diskusi.
5. [Skor 5] Membangun profil profesional di LinkedIn dan berjejaring dengan pakar edukasi.

#### Butir 17

5. [Skor 5] Menambahkan takarir teks otomatis yang akurat di sepanjang durasi video.

### DIMENSI 4: ETIKA & KEAMANAN DIGITAL (C4 - EKD)

#### Butir 19
**Skenario:** Anda mendapat email peringatan bahwa akun LMS akan diblokir dan diminta mengeklik tautan verifikasi.

**Opsi Jawaban:**
1. [Skor 1] Karena panik, langsung mengeklik tautan tersebut dan memasukkan kata sandi LMS.
2. [Skor 2] Membalas email tersebut dengan memohon agar admin tidak memblokir akun Anda.
3. [Skor 3] Mengeklik tautan, namun segera menutupnya karena tampilan halaman mencurigakan.
4. [Skor 4] Menghubungi teman grup kelas untuk bertanya apakah mereka mendapat email serupa.
5. [Skor 5] Melaporkan email tersebut sebagai phishing dan mengaktifkan keamanan ganda akun.

#### Butir 20
**Skenario:** Anda mendokumentasikan foto siswa yang tantrum di kelas untuk diunggah ke Instagram pribadi.

**Opsi Jawaban:**
1. [Skor 1] Mengunggah foto tersebut tanpa sensor wajah dengan keterangan nama asli anak.
2. [Skor 2] Mengunggah foto tersebut dengan keterangan yang menyalahkan pola asuh orang tua.
3. [Skor 3] Mengunggah foto tersebut di fitur Close Friends agar hanya teman dekat melihatnya.
4. [Skor 4] Mengunggah foto papan tulis kosong sebagai latar keluh kesah tanpa melibatkan siswa.
5. [Skor 5] Memilih tidak mengunggah data atau wajah siswa demi mematuhi etika profesi.

#### Butir 21
**Skenario:** Tersebar pesan di WhatsApp bahwa pemerintah membagikan kuota gratis lewat tautan bit.ly mencurigakan.

**Opsi Jawaban:**
1. [Skor 1] Langsung mengisi formulir dengan data identitas asli dan menyebarkannya ke grup lain.
2. [Skor 2] Hanya mengisi data identitas Anda sendiri demi mendapat kuota tanpa menyebarkannya.
3. [Skor 3] Mencoba mengisi dengan data identitas palsu sekadar iseng menguji kebenaran hadiah.
4. [Skor 4] Mengabaikan pesan tersebut karena merasa tidak membutuhkan bantuan kuota gratis.
5. [Skor 5] Memverifikasi tautan lewat kanal resmi pemerintah dan mengedukasi grup tentang bahaya hoax.

#### Butir 22
**Skenario:** Anda menemukan artikel blog yang isi resensinya sangat sesuai untuk tugas UTS resensi jurnal Anda.

**Opsi Jawaban:**
1. [Skor 1] Melakukan penyalinan utuh 100% dan menyerahkannya sebagai tugas UTS mandiri.
2. [Skor 2] Mengambil mayoritas isi teks blog namun mengganti beberapa istilah kunci saja.
3. [Skor 3] Menggunakan alat penerjemah otomatis agar struktur kalimat berubah untuk hindari plagiasi.
4. [Skor 4] Menulis ulang gagasan utama dengan gaya bahasa sendiri tanpa mencantumkan sumber rujukan.
5. [Skor 5] Mensintesis ide dari blog dengan jurnal asli dan mencantumkan sumber rujukan jujur.

#### Butir 23
**Skenario:** Anda bekerja di depan laptop lebih dari 10 jam berturut-turut hingga mata perih dan leher sakit.

**Opsi Jawaban:**
1. [Skor 1] Terus memaksakan diri bekerja hingga pagi dengan bantuan minuman berenergi.
2. [Skor 2] Berhenti mengerjakan tugas sama sekali selama berhari-hari demi memulihkan waktu tidur.
3. [Skor 3] Menggunakan obat tetes mata dan vitamin lalu melanjutkan kerja tanpa istirahat.
4. [Skor 4] Mengurangi tingkat kecerahan layar laptop dan baru beristirahat jika sudah pusing.
5. [Skor 5] Menerapkan metode Pomodoro dan menjaga postur ergonomis selama bekerja digital.

#### Butir 24
**Skenario:** Akun SIAKAD Anda disusupi orang lain karena ada mata kuliah penting yang terhapus dari KRS.

**Opsi Jawaban:**
1. [Skor 1] Membiarkannya berlalu dan berharap sistem akan kembali normal dengan sendirinya.
2. [Skor 2] Mengeluh dan marah di media sosial dengan menyebut akun resmi kampus Anda.
3. [Skor 3] Berusaha membuat akun mahasiswa baru agar terhindar dari penyusup di sistem lama.
4. [Skor 4] Segera membuka profil akun dan mengganti kata sandi lama dengan kombinasi baru.
5. [Skor 5] Mengganti sandi ke standar kuat dan melaporkan aktivitas mencurigakan ke admin IT.

### DIMENSI 5: SOLUSI INOVASI DIGITAL (C5 - SID)

#### Butir 25
**Skenario:** Saat sidang proposal daring, dosen menguji menginterupsi bahwa suara Anda sama sekali tidak terdengar.

**Opsi Jawaban:**
1. [Skor 1] Langsung mematikan laptop dan menyerah karena merasa sidang sudah pasti gagal.
2. [Skor 2] Terus berbicara sambil memukul-mukul keyboard berharap suara muncul kembali.
3. [Skor 3] Meminta bantuan orang sekitar untuk berteriak ke mikrofon laptop agar terdengar.
4. [Skor 4] Meminta izin keluar sebentar untuk melakukan mulai ulang perangkat dan bergabung kembali.
5. [Skor 5] Mereset driver mikrofon lewat pengaturan atau berpindah perangkat login secara cepat.

#### Butir 26

3. [Skor 3] Membuka kuis di proyektor lalu meminta seluruh siswa menebak jawaban serentak.
4. [Skor 4] Membuka kuis di proyektor lalu meminta siswa menulis jawaban di selembar kertas.

4. [Skor 4] Menghubungi teman yang ahli dan meminta tutorial langkah demi langkah lewat Zoom.
5. [Skor 5] Mempelajari tutorial fungsi Excel secara mandiri di internet dan mengaplikasikannya langsung.

5. [Skor 5] Melakukan fitur Share Screen di Zoom sambil menduplikasi tampilan ke proyektor fisik.

3. [Skor 3] Menyuruh siswa beralih ke ujian CBT lewat HP pribadi padahal server pusat mati.
4. [Skor 4] Menyiapkan naskah soal darurat dalam bentuk fisik untuk dibagikan ke seluruh kelas.
5. [Skor 5] Melakukan backup data jawaban manual dan beralih ke platform cloud cadangan.
